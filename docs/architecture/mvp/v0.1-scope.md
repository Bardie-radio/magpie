# Magpie MVP v0.1 scope

Enough to ship Magpie beside Kithara + Bes + Plume in the reference Compose stack.

**Status:** Magpie app implemented for Kithara **Phase 3** — register, search, cache-first play, PCM to session FIFO (YoutubeExplode + FFmpeg.AutoGen; `sine` track for local proof). See Kithara [implementation-plan](https://github.com/Bardie-radio/kithara/blob/main/docs/architecture/mvp/implementation-plan.md) Phase 3.

## In scope

- Container `magpie`; join secret; register with capabilities `search`, `play`, `pause`
- gRPC: `Register`, `Health`, `Search`, `StartTrack`, `StopTrack`, `TrackStatus`
- Quicksearch + regular search (title mandatory; artist/owner encouraged)
- Plain-text → video id / YouTube URL fallback
- Cache-first play; download + Tune create/update on miss
- Blob put/get via shared storage contract
- Canonical PCM to session FIFO; W3C `traceparent`; OTLP `bardie.source.magpie`
- Parallel track-job limit (enforce internally)

## Out of scope

- Hosting FFmpeg or `/stream` (Kithara)
- Owning user DB or auth
- Standalone mode / optional HTTP download surface ([03-standalone-and-http](../03-standalone-and-http.md) — **future planned**; leave Command + sink + façade seams in MVP)
- Starling/Catbird behaviour
- Non-YouTube extractors beyond what MVP ytdl needs (expand later)

## Implementation checklist

- [x] gRPC server + Register/Health against Kithara
- [x] Work verbs as **commands** / handlers; gRPC as façade only (seam for later HTTP)
- [x] Media **sink** behind an interface (FIFO write loop in Magpie; `IFifoAudioSink` in Module.Source)
- [x] Search (quick + structured) + id/URL fallback (+ `sine` local proof)
- [x] StartTrack cache path + download miss path + StopTrack
- [x] Blob storage client (`IModuleBlobStorageClient`)
- [x] Tune ensure/update handshake with Kithara (`Library.EnsureTune`)
- [x] TrackStatus stream + OTLP (`bardie.source.magpie` via Module.Hosting)
- [x] Compose snippet + join secret wiring (`local/compose.phase3.yml`)
- [x] Spike/load test: one Struna play through Magpie end-to-end (run `phase3-source-smoke.sh`)
